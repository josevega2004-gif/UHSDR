# Build options that do not compile, recorded so that `make build-config-check` can tell a mode that
# has been broken for years from one that broke yesterday.
#
# Every line is `OPTION path/to/file.c`, where the path is relative to mchf-eclipse and is one of the
# translation units that fail with `-D<OPTION>` added to the build's own command line.  A file that
# fails and is not listed here is a regression; a file listed here that compiles again has to be
# deleted from this list, which is also the moment the option becomes buildable.  An option with no
# lines here compiles completely, and there are more of those than there were before this file:
# CODEC_USE_SPI, DEBUG_BUILD, IS_SMALL_BUILD, USE_GFX_SSD1289, USE_SMALL_HILBERT_DECIMATION_FILTERS
# and USE_USBDRIVE each build every one of the 476 translation units of the mcHF configuration.
#
# Two of those are green for a reason worth stating, because "compiles" is not the same as "means
# something": CODEC_USE_SPI is named by no source file at all (0 of 476 units can see it), and
# DEBUG_BUILD reaches one unit, hardware/uhsdr_board.c, where its block sits inside an `#if 0` - the
# `#error "Debug Build No Longer Supported"` in it is dead, so switching the option on does nothing
# rather than saying what the author intended it to say.
#
# Generated and checked by support/build_config_check.py, which sweeps the value-less commented
# `#define`s of hardware/uhsdr_board_config.h and hardware/uhsdr_board.h.  Options that need more
# than their own -D to be built at all are named with `SKIP OPTION` below, with the reason.

# Fast convolution RX filtering.  hardware/uhsdr_board_config.h:89 has been commented out since
# 3434f9db (2018-08-22), and until now the branch could not be built at all: it had drifted from every
# API the 2019 restructurings moved (adb.i_buffer, fm_squelched, ts.dsp_active, AudioDriver_FreqConversion,
# the extra `muted` argument on the RX processor), it enqueued the noise reducer's mmb buffers as though
# they were its own, its per-partition masks were never generated because nothing called
# AudioDriver_SetConvolutionFilter(), it called AudioDriver_RxAgcWdsp(), which has not existed in the
# tree since the same 1c09d16c that broke the call signature, and it designed a 250-2700 Hz bandpass
# against IQ_SAMPLE_RATE while handing the worker decimated samples.  It is repaired rather than
# deleted, and reads as an alternative RX *filter* now instead of a half-copied RX *chain*.
#
# What is not settled by this file is whether the filter is better than the Hilbert path it replaces;
# support/digi measures that, and the answer is in the README.  Until it is built into a radio nobody
# should hear a difference, because no shipping configuration defines the option.

# The noise reducer that predates USE_ALTERNATE_NR.  hardware/uhsdr_board_config.h:93.
#
#   drivers/ui/menu/ui_menu_internal.h:226-228   three notch CONFIG_ enumerators are declared twice
#                                  when this option is on, once for each side of a conditional block,
#                                  so ui_menu.c, ui_menu_internal.c and ui_menu_structure.c all stop
#   drivers/ui/ui_configuration.c  reads dsp_params_t.nr_delaybuf_len and DSP_NR_BUFLEN_DEFAULT,
#                                  _MIN and _MAX, none of which exist since the delay buffer length
#                                  went away with the alternate NR's own buffer sizing
OBSOLETE_NR drivers/ui/menu/ui_menu.c
OBSOLETE_NR drivers/ui/menu/ui_menu_internal.c
OBSOLETE_NR drivers/ui/menu/ui_menu_structure.c
OBSOLETE_NR drivers/ui/ui_configuration.c
